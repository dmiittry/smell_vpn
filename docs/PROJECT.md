# Назначение проекта

Sme11_VPN — клиент к уже существующему VLESS/Reality серверу. Клиент не предоставляет сервер, подписку или аккаунт VPN-провайдера.

Приоритеты: простой интерфейс, явный выбор приложений, понятная диагностика сбоев.

Версия 0.3.0: Android и Windows x64, защищённый каталог до 20 профилей, TCP/Reality, импорт из буфера и ручная форма. Минимальный главный экран показывает зелёный успех с задержкой только после HTTPS-проверки текущего сервера; при неудаче — красный статус и текст ошибки. Ручное переключение по умолчанию, необязательный URLTest-автовыбор. Подключение запускается пользователем. Android уведомляет о статусе, активном сервере и скорости. Служебный журнал сохраняется независимо от Flutter UI; потеря канала управления не объявляется остановкой туннеля.

В Android доступны приложения с активностью запуска. В Windows показаны запущенные доступные процессы; установленное приложение можно добавить через выбор EXE. Переименование или перемещение EXE требует обновить выбор.

Состояние ядра и сетевые ошибки отображаются отдельно. Запущенный TUN не означает, что удалённый сервер доступен. Логи не обещают определить точную причину уничтожения процесса операционной системой: часть событий может не успеть сохраниться.
