# Sme11_VPN 0.3.1 — 2026-10-29

## Удаление серверов

В карточке каждого сервера появилась красная кнопка «Удалить». Диалог показывает имя и просит подтверждение. Если VPN работает, после подтверждения туннель останавливается, затем профиль удаляется. При ошибке остановки профиль сохраняется. Автоматическое повторное подключение после удаления не выполняется. Удаление относится только к локальному профилю; сервер и учётная запись на нём не удаляются.

Удаление выбранного профиля выбирает первый оставшийся; удаление невыбранного сохраняет выбор. Последний профиль оставляет пустой каталог и выключает автовыбор. Пустой каталог сохраняется явно, поэтому старый профиль из миграции не появляется заново. Изменение памяти выполняется после успешной записи. Во время записи изменение каталога и подключение заблокированы.

## Автовыбор

Исправлены два дефекта: включение автоматики передавало выбор группе URLTest без обязательного свежего измерения, а выключение возвращало ранее сохранённый ручной профиль, даже если фактически использовался другой.

- При включении без VPN профили проверяются временным proxy-сервисом без TUN; сохраняется рабочий профиль с меньшей задержкой. Старый удачный пинг не заменяет новую проверку.
- На работающем ядре сначала проверяются все профили, затем пересчитывается выбор URLTest и подтверждается, что выбран успешно проверенный профиль. Только после этого selector переключается на auto. Если все недоступны, команда завершается ошибкой с сохранением прежнего выбора.
- При запуске автоматического режима ядро переводится в auto после готовности управления и подтверждения доступности. Выключение автоматики сохраняет фактический сервер текущего соединения.
- Нулевая или отрицательная задержка не является успехом. Ответы старой сессии не могут продолжить переключение в новой сессии.

Фоновый выбор остаётся в URLTest ядра: интервал одна минута, допуск 100 мс. Это не обещает мгновенного восстановления или максимальной пропускной способности; переключение может оборвать соединения. При отказе всех профилей уже работающая группа может сохранять прежний выбор, но интерфейс не подтверждает его доступность без успешной HTTPS-пробы. Проверочный ресурс gstatic.com также может быть недоступен. Автоматика не восстанавливает уничтоженный Android-сервис.
