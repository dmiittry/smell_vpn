# Правила для AI

Канонические правила находятся в [../AI_RULES.md](../AI_RULES.md). Правила пользователя имеют приоритет над локальными рекомендациями.

Отдельное правило VPN: изменение политики маршрутизации, DNS, kill switch и хранения секретов нельзя скрывать за косметическим обновлением. Поведение и ограничения должны быть отражены в документации.
