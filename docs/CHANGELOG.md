# История изменений

## 0.3.0 — 2026-10-22

- Главный экран упрощён: сервер, круглая кнопка, статус, пинг и выбор маршрутизации. Убраны рекламные заголовки, орбиты и дублирующие карточки.
- Успех показывается зелёным только после HTTPS-проверки активного сервера. Ошибка запуска или проверки — красным с текстом и переходом к логам.
- Пинг обновляется вручную, после подключения/смены сервера и раз в минуту при активном интерфейсе. После 90 секунд результат не подтверждает соединение.
- Ответы проверок предыдущего сервера или сессии игнорируются. Неудачная проверка не останавливает VPN-сервис.
- Добавлены проверки состояний, гонок и контрольные изображения; подготовлена публикация исходников в dmiittry/smell_vpn.

## 0.2.1 — 2026-10-15

- Потеря CommandClient больше не считается остановкой VPN. Три ограниченные попытки восстановления управления; запоздалые callbacks старого клиента игнорируются.
- Исправлены повторные Flutter-подписки, дублирование событий и гонка старого onLost после выбора новой физической сети.
- Ошибка отдельного соединения сохраняется в журнал, но не показывает баннер отказа запуска работающего VPN.
- Независимые квоты: 500 важных, 1000 сетевых и 300 подробных записей. Важные события инициируют запись сразу; медленный диск не создаёт очередь полных снимков.
- Независимый атомарный Android-журнал: lifecycle, сеть, питание, доступная история ApplicationExitInfo и безопасные сводки ошибок ядра при закрытом UI.
- Пустой START_STICKY-перезапуск заменён явной остановкой: конфигурация хранится только в памяти, после уничтожения процесса подключение остаётся ручным.
- Штатное отключение из уведомления распознаётся отдельно от неожиданной остановки.

## 0.2.0 — 2026-10-06

- Защищённый каталог до 20 профилей, перенос 0.1.x с сохранением старого ключа и проверкой записи.
- Экран «Серверы»: ручной выбор, активный профиль, HTTPS-пробы, задержка, возраст результатов и ошибки.
- Selector для ручного переключения и необязательный URLTest раз в минуту, допуск 100 мс; direct не является запасным сервером.
- Локальный API на случайном loopback-порту с токеном, подтверждение выбора ядром; правила выбранных приложений сохранены.
- Android 13+ запрашивает уведомления; отказ не блокирует VPN. Постоянное уведомление показывает активный профиль и реальную скорость в битовых единицах.
- Локальная модификация SDK вместо изменений глобального pub-cache; счётчики и управление сохраняются при закрытии/повторном открытии Activity.
- Исправлено отображение скорости в интерфейсе: libbox возвращает байты/с.
- Добавлены проверки переноса, отказа записи, отката выбора и настоящего API ядра.

## 0.1.1 — 2026-10-06

- Исправлена классификация логов Android: текстовые INFO/DEBUG/TRACE больше не становятся ERROR из-за неверных метаданных адаптера.
- Сохранённые записи ядра переклассифицируются при загрузке без удаления сообщений и временных меток.
- Ложные сообщения о неработающем VPN больше не создаются обычными диагностическими строками. Настоящие ERROR/FATAL/PANIC и fault-события сохраняются.
- Windows также определяет уровень только по заголовку строки, а не по словам внутри сообщения.
- Добавлены четыре регрессионных теста. Пользователь уточнил, что интернет на POCO работает; скриншот подтвердил ложный баннер «VPN не удалось запустить» при работающем туннеле.

## 0.1.0 — 2026-10-06

- Создан Sme11_VPN на Flutter для Android и Windows.
- Добавлены минимальный тёмный интерфейс и адаптивная навигация.
- Реализован один VLESS/Reality TCP профиль с проверкой полей и защищённым хранением.
- Добавлены ручной ввод и вставка одной конфигурации из буфера.
- Реализованы выбранные приложения и режим VPN для всех.
- Добавлены диагностика ядра, фильтры уровней, поиск, порядок записей, экспорт и копирование TXT.
- Добавлены проверка непустого allowlist и сохранение ошибки после остановки ядра.
- Windows ядро запускается со stdin и привязывается к Job Object.
- Добавлены тесты и русская документация.
- Добавлен отдельный сценарий сборки Android с проверкой регистрации плагинов.

## Windows 0.2.1 — 2026-10-21

- Впервые собраны Windows EXE, установщик для текущего пользователя и переносимый ZIP.
- Ядро sing-box 1.13.9, libcronet, лицензии и Visual C++ Runtime включены в комплект.
- Добавлены scripts/build_windows.ps1 и упаковка Inno Setup; Developer Mode не изменяется.
- Исправлена блокирующая /WX ошибка затенения переменной PID в Windows runner; обновлена подпись версии в UI.
- Установка проверена, EXE совпадает со сборкой. Реальное VPN-соединение на ПК ещё требует проверки с пользовательским сервером.
