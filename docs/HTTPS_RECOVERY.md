# Восстановление HTTPS панели после смены IP

## Выполнено 2026-10-29

Панель x-ui работала, но сертификат содержал старый IP в Subject Alternative Name. Переход по новому IP вызывал ошибку проверки имени сертификата. Подключение по SSH и проверка выполнены по прямому поручению владельца сервера.

- До изменений сохранены сертификат, приватный ключ, прежняя ACME-конфигурация и согласованная SQLite-копия базы панели в закрытом каталоге `/root/sme11-https-backups/` на сервере.
- Через установленный acme.sh 3.1.7 выпущен сертификат Let's Encrypt для нового IP, профиль `shortlived`, ключ EC-256.
- Сертификат установлен в прежние пути `/root/cert/ip/fullchain.pem` и `/root/cert/ip/privkey.pem`. Права приватного ключа — 600, владелец root.
- Для применения выполнен перезапуск x-ui. Продление сохраняет сертификат в эти же пути и выполняет `systemctl restart x-ui`.
- Старый IP исключён из списка автопродления командой acme.sh `--remove --ecc`; прежние файлы сертификата и резервная копия сохранены.
- Действующий cron проверяет продление четырежды в сутки; cron и x-ui активны. На момент проверки срок сертификата — до 5 ноября 2026, 00:08:34 UTC; следующая плановая дата продления в ACME — 1 ноября.
- HTTPS-страница входа отвечает HTTP 200 при стандартной проверке доверия и IP сертификата. Конфигурации inbound’ов сопоставлены с резервной копией и совпадают. Работа VPN через мобильного оператора этой проверкой не подтверждается.

## При следующей смене IP

IP должен совпадать с SAN сертификата. Старый IP-сертификат не подходит новому адресу. Следует выпустить новый сертификат и обновить запись автопродления. Для standalone HTTP-01 проверки порт TCP 80 должен быть доступен извне во время выпуска и продления; не занимайте его другим сервисом без изменения способа проверки.

IP-сертификаты Let's Encrypt действуют 160 часов, поэтому автоматическое продление обязательно. Не отключать проверку сертификата в браузере или клиенте. Доменное имя с обновляемой DNS-записью уменьшит зависимость адреса панели от смены IP, но переход на домен в этой работе не выполнялся.

Источники: [Let's Encrypt: IP и короткие сертификаты](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability), [acme.sh: выбор профиля и срок продления](https://github.com/acmesh-official/acme.sh/wiki/Profile-selection).
