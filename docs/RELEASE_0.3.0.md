# Sme11_VPN 0.3.0 — 2026-10-22

## Что изменилось

Главный экран содержит выбор сервера, круглую кнопку питания, состояние и пинг. Убраны «Свобода подключения», «Ваш сервер…», орбиты и дополнительные карточки. Сохранились серверы, маршрутизация по приложениям и журналы с фильтрами. На ПК используется боковая навигация, на телефоне — нижняя.

| Состояние | Отображение |
| --- | --- |
| VPN отключён | Нейтральная кнопка, «Нажмите для подключения» |
| Запуск | Индикатор и «Подключение…» |
| TUN запущен, проба ещё не завершилась | Нейтральный статус, «Проверка соединения…» |
| Успешная свежая HTTPS-проба | Зелёная кнопка, «Подключено» и задержка в мс |
| Ошибка запуска | Красная кнопка, причина ошибки и переход к логам |
| Проба через сервер не прошла | Красная кнопка, текст ошибки, «Пинг недоступен»; VPN можно отключить кнопкой |

Пинг — задержка HTTPS-запроса через конкретный VLESS/Reality outbound к `https://www.gstatic.com/generate_204`. Проверка не измеряет пропускную способность и не доказывает работоспособность всех сайтов или системной маршрутизации. Проверочный ресурс также может быть недоступен. Неудачная проба сама по себе не останавливает туннель.

После подключения и смены фактического сервера результат сбрасывается и измеряется заново. Проверка повторяется раз в минуту при открытом приложении; её можно запустить кнопкой обновления. Результат старше 90 секунд не подтверждает соединение. Запоздавшие ответы предыдущего сервера или сессии игнорируются.

## Проверки

37 Flutter-тестов: навигация и формы на ширинах 320, 390 и 1180, цвет успешного/ошибочного состояния, обязательный пинг при успехе, ошибка при работающем сервисе, смена сервера во время пробы, отключение и устаревший результат. Изображения в `docs/screenshots/home_connected.png` и `home_error.png` получены widget-тестами на синтетическом профиле; задержка 42 мс тестовая.

Реальное соединение с пользовательским сервером, сон телефона, TUN и разделение трафика требуют ручной проверки. Android использует прежнее ядро 1.14.0-alpha.20; Windows — 1.13.9. Обновление интерфейса не устраняет само по себе системное завершение Android-процесса.

## Сборки

Android для POCO: `dist/Sme11_VPN-0.3.0-arm64-v8a.apk`. Windows: `dist/Sme11_VPN-0.3.0-Windows-x64-Setup.exe` и `dist/Sme11_VPN-0.3.0-Windows-x64-Portable.zip`. Проверенные результаты сборки и контрольные суммы фиксируются в `dist`; готовые файлы не добавляются в историю Git.

Финальный статический анализ без замечаний; 37 Flutter-тестов прошли; Release Android для трёх ABI и Windows x64 собраны, установщик скомпилирован. Суммы: `dist/SHA256-Android-0.3.0.txt` и `dist/SHA256-Windows-0.3.0.txt`. Подпись Android совпадает с 0.2.1; Windows-установщик 0.3.0 поверх установленного приложения в этой проверке не запускался.

Перед обновлением отключите VPN. Android APK подписан прежним локальным debug-ключом и предназначен для личного тестирования; удалять приложение перед обновлением не нужно. Windows-установщик не подписан сертификатом издателя. Для TUN на Windows запуск программы требует прав администратора.
