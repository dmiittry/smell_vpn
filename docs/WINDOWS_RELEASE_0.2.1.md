# Sme11_VPN 0.2.1 для Windows

Дата: 2026-10-21. Поддерживаемая цель сборки — Windows 10/11 x64, установленный минимум установщика — Windows 10 1809.

## Готовые файлы

- `dist/Sme11_VPN-0.2.1-Windows-x64-Setup.exe` — установщик, 25 374 375 байт.
- `dist/Sme11_VPN-0.2.1-Windows-x64-Portable.zip` — переносимая программа, 34 119 359 байт.
- `dist/SHA256-Windows-0.2.1.txt` — контрольные суммы.

SHA-256 Setup: `45356b20cf5de4e67e93f7ffc3e0e493a5347322802919750dfe31f13793f54f`.

SHA-256 ZIP: `f254dab42f752eedfabd8ff0be17281b0655c2ee84ef03df605decda59940653`.

Программа установлена для текущего пользователя в `%LOCALAPPDATA%/Programs/Sme11_VPN`; пункт Sme11_VPN добавлен в меню «Пуск». Для подключения VPN запускайте её от имени администратора. Конфигурацию добавьте вручную или из буфера, выберите нужные EXE. Переносимую версию нужно полностью распаковать и запускать `sme11_vpn.exe` вместе с соседними библиотеками и каталогами.

## Изменения и документы

Созданы `scripts/build_windows.ps1`, `packaging/windows/Sme11_VPN.iss`, `packaging/windows/INSTALL_RU.txt` и этот документ. Изменены `.gitignore` (локальные инструменты), `windows/runner/flutter_window.cpp` (имена переменных PID для /WX), `lib/ui/app.dart` (версия 0.2.1), README и документы DEPLOY, TESTING, DECISIONS, CHANGELOG, ROADMAP, DEPENDENCIES и индекс docs.

Повторная сборка: `scripts/build_windows.ps1`. Опция `-SkipChecks` предназначена для повторной упаковки после уже успешных анализа и тестов. Windows-регистратор генерируется Flutter; его файлы вручную не редактируются. Используются закреплённые зависимости и проверенное ядро sing-box 1.13.9. Microsoft Runtime копируется app-local, отдельный системный redistributable пользователю не нужен.

## Проверки и ограничения

Анализ без замечаний, 30 Flutter-тестов прошли. MSVC Release и Inno Setup завершились успешно. Программа открывала главный экран и логи без ошибок инициализации. Установка завершилась с кодом 0; установленный EXE совпал со сборкой по SHA-256. Ядро из установленного комплекта запускается. Дополнительный UI-проход итоговой установленной копии остановлен пользователем Escape; автоматизация после этого прекращена.

Подключение к реальному серверу и TUN на этом ПК не выполнялись. Не проверены реальные IPv4/IPv6/DNS, скорость и маршрутизация выбранных EXE. Приложение не подписано сертификатом издателя; Windows может показать SmartScreen. Kill switch и Windows-статистика скорости отсутствуют. Службы и автозапуск не устанавливаются. Лицензии включены; исходный код находится в текущем проекте и должен предоставляться вместе с производными сборками при их дальнейшем распространении.
