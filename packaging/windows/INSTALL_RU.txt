Sme11_VPN для Windows 10/11 x64

Приложение устанавливается для текущего пользователя. Профили и журналы сохраняются в пользовательском каталоге данных и не удаляются при обычном удалении программы.

Для создания VPN-туннеля нужны права администратора. Запускайте Sme11_VPN через «Запуск от имени администратора», используя свою учётную запись. Вход в VPN выполняется только вручную.

Добавьте собственный VLESS/Reality TCP-профиль из буфера или вручную. На вкладке «Приложения» выберите EXE, которым нужен VPN; остальные программы используют обычную сеть. У приложений могут быть отдельные дочерние EXE, которые нужно выбрать дополнительно.

VPN-ядро и необходимые библиотеки входят в комплект. Ничего скачивать при установке не требуется. Службы и автозапуск не устанавливаются.

При проблемах откройте «Логи», выберите «Все» и экспортируйте журнал. Запущенный туннель не гарантирует доступность удалённого сервера. Kill switch отсутствует: при остановке VPN выбранные приложения могут использовать обычную сеть.

Сборка для личного тестирования. Исполняемые файлы приложения не подписаны сертификатом издателя; Windows может показать предупреждение SmartScreen.
